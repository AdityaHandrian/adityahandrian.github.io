what i’m researching.

Undergraduate thesis, proposal stage, Oct 2026

Temporal and seasonal fashion trend identification from runway images, using zero-shot attribute extraction with vision-language models and style clustering

Runway images carry rich visual design information, but there are far too many of them to analyze by hand without bias. This research identifies fashion trends automatically: a vision-language model reads design attributes straight from the images without task-specific training, the results are grouped into style clusters, and each attribute and style is tracked across seasons.

The goal is a list of the clothing styles and attributes that trended from 2019 to 2023, obtained without a large labeled dataset.

Advisor
Shintami Chusnul Hidayati, Ph.D.
Keywords
Fashion, clustering, runway, vision-language models, zero-shot

  1. Data

    16,298 → 14,401

    Women’s ready-to-wear looks from Vogue Runway, 2019 to 2023: 19 brands that showed in all four seasons every year, filtered down.

  2. Attributes

    CLIP, SigLIP, MLLM

    Zero-shot extraction of 9 attribute categories adapted from Fashionpedia, using prompt ensembles and ontology-constrained prompting. Models are combined by majority and weighted voting, scored with Macro F1 against manual labels.

  3. Styles

    PCA / UMAP × K-Means / HDBSCAN

    Dimensionality reduction and clustering combinations are compared to group the attribute representations into style clusters.

  4. Trends

    5 trajectory types

    Each attribute’s and style’s popularity over time is labeled emerging, declining, stable, seasonal, or volatile.

Chain Transfer RBSM

Transportation problem heuristic

2026Operations research, C++

One extra move that lets RBSM reach the optimal cost far more often.

RBSM only moves excess units straight from an over-allocated row to an under-allocated one. Our change lets an already-satisfied row act as a go-between (ER → S → NS across two columns) when that path is cheaper, and the rewritten search keeps each iteration at O(m²n), the same class as the original, instead of O(m³n²).
